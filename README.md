# Lateri Home Delivery Partner — Final Working Core

A single mobile-first web/PWA app containing Customer, Shop, Delivery Partner and Admin panels with a persistent JSON database.

## Run
1. Install Node.js 18+.
2. Open this folder in terminal.
3. Run `npm start`.
4. Open `http://localhost:3000`.

- delivery order acceptance/completion
